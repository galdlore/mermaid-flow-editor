Privacy Policy for Mermaid Flow Editor

Last updated: November 15, 2026

Overview

Mermaid Flow Editor is a local Markdown and Mermaid diagram editor that runs directly in your browser. Protecting your privacy is a core principle of this extension.

Data Collection and External Transmission

Mermaid Flow Editor does not collect, transmit, store, or share any personal information, browsing history, analytics, or user documents with external servers or third parties. All Markdown editing and Mermaid diagram rendering happen locally on your device.

Local Browser Storage

To improve usability between sessions, the extension stores the following preferences locally in your browser via localStorage:

  • Your current unsaved Markdown draft text
  • Your selected interface language (English or Japanese)
  • Your preferred Tab indentation size (2 or 4 spaces)

This data remains strictly inside your local browser storage and is never transmitted externally. You can clear it at any time through your browser settings.

Local File Access

When you use the Open, Save, or Save As actions, the extension reads from or writes to only the local files you explicitly select through your browser's file picker.

Permissions

This extension does not request host permissions to read web pages you visit and does not run background tracking or analytics scripts.

Changes to This Policy

If the extension's data handling changes in a future update, this privacy policy will be updated accordingly.

Contact

If you have any questions about this privacy policy, please open an issue at https://github.com/galdlore/mermaid-flow-editor/issues.
