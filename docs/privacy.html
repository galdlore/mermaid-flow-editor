Privacy Policy for Mermaid Flow Editor

Last updated: November 19, 2026

Overview

Mermaid Flow Editor is a local Markdown and Mermaid diagram editor that runs directly in your browser. Protecting your privacy is a core principle of this extension.

Data Collection and External Transmission

By default, Mermaid Flow Editor does not collect, transmit, store, or share any personal information, browsing history, analytics, or user documents with external servers or third parties. All Markdown editing and Mermaid diagram rendering happen locally on your device.

If you optionally configure a remote save destination (such as your own OpenCloud/WebDAV server or custom HTTP API endpoint) in Settings, the extension communicates directly with the endpoint URL you explicitly entered—only when you trigger a cloud open, directory listing, folder creation, cloud save, connection test, or enable sync-on-save. No telemetry or developer-hosted servers are involved.

Local Browser Storage & Encrypted Credentials

To improve usability between sessions, the extension stores the following preferences locally in your browser via localStorage:

  • Your open Markdown tabs and unsaved draft text
  • Your selected interface language (English or Japanese) and editor mode
  • Your preferred Tab indentation size (2 or 4 spaces)
  • Your non-secret remote save endpoint settings (if configured)

By default, remote API tokens and passwords are held in memory only and cleared when the tab closes. If you explicitly choose to persist remote credentials across sessions, they are encrypted locally in your browser using AES-256-GCM with a key derived via PBKDF2-SHA256 from a passphrase you supply. The passphrase itself is never stored.

All stored data remains strictly inside your local browser storage and can be cleared at any time through the Settings dialog or your browser settings.

Local File Access

When you use the Open, Save, Save As, or Export actions, the extension reads from or writes to only the local files you explicitly select through your browser's file picker or drag onto the editor.

Permissions

This extension does not request broad host permissions to read web pages you visit and does not run background tracking or analytics scripts. Optional host permissions (optional_host_permissions) are requested only at runtime for the specific origin of a remote WebDAV/API destination that you explicitly configure and test or save to.

Changes to This Policy

If the extension's data handling changes in a future update, this privacy policy will be updated accordingly.

Contact

If you have any questions about this privacy policy, please open an issue at https://github.com/galdlore/mermaid-flow-editor/issues.
